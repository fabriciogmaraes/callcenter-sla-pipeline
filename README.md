# Pipeline de Atendimento de Call Center (SDD)

Projeto da atividade "De Spec a Código" (PPgTI/UFRN).

## Rodar
```
pip install pytest
python -m pytest tests/ -v
python main.py
```

## Estrutura
- `docs/escopo.md` — Etapa 1
- `docs/spec.md` — Etapa 2 (user stories, PRD, critérios de aceite, plano de tarefas)
- `ingest/`, `rules/`, `storage/`, `main.py` — Etapa 3 (implementação)
